# Slime Time

2D pixel-art game in **Godot 4.7** (GDScript). A slime glides through a pitch-black maze; its goo trail reveals the map, moving drains the slime meter, and a golden chalice is the exit. Full design and build phases: [docs/game-design.md](docs/game-design.md). **All 6 build phases are done.** Further work is tuning, content and polish requested by the user.

## Pixel-art rules (keep these consistent)
- Base resolution **320x180**, window 1280x720, stretch mode `viewport` + `integer` scaling.
- **16x16 tiles**; slime frames are 20x20 (≈14 px body, room to squash/stretch). Nearest-neighbor filtering is the project default; never enable texture filtering. UI text uses the generated slimy pixel font (`assets/fonts/pixel.fnt`: 5x7 glyphs with goo drips in the 2 px below the baseline, shaded white/grey so it tints well; project default font): size 8 for text, 16 for titles (integer-scaled). Text color follows the equipped skin via `SkinText` (`scripts/ui/skin_text.gd`): labels made with `UIKit.make_label` using GOLD/TEXT/TEXT_DIM become title/text/dim roles; rainbow cycles.
- `snap_2d_transforms_to_pixel` is on; avoid sub-pixel scaling or rotation of sprites.
- Colors come from the palette in `tools/make_placeholder_art.py` (`PAL`). New art should reuse it.

## Layout
- Scenes: `title.tscn` (main scene: start page) → `level_select.tscn`, `skins.tscn`, `controls.tscn` (remapping + sound toggle + volume slider), `main.tscn` (gameplay, includes the pause menu), `victory.tscn` (after level 10). Menu scripts in `scripts/ui/` (`ui_kit.gd` = shared theme (beveled nine-slice buttons, panels, pixel checkbox/slider from `assets/ui/`) + helpers (`add_panel`, `make_icon`, `go` = goo-wipe scene change) + button click sound, `menu_backdrop.gd` = `MenuBackdrop` drifting dim maze + mist behind every menu, `transition.gd` = autoload `Transition` goo wipe (`go(scene)`, `reveal()` on level start; textured goo in the skin's shades from `goo_wipe.gdshader`, a random rainbow color each time with the rainbow skin), `color_wheel.gd`, `pause_menu.gd`).
- `scripts/game.gd` — gameplay: story level or randomizer maze (`random_seed`; a win or a dry-up moves on to a new random maze), tile variant choice, fog/trail reveal on a 2 px grid with stepped fade-back (`FADE_AFTER`/`FADE_ALPHA`; walls dim in lockstep, `WALL_FOG_ALPHA` darker), skin colors, glow, splat screen shake, win/lose flow: a dry-up offers RESTART (or NEW MAZE) / UPGRADES (`retry()`, `go_to_upgrades()`: the upgrades screen's back button then says PLAY and returns to the level via `Progress.return_to_game`); a win offers REPLAY / NEXT (`replay()` / `play_next()`, buttons via `hud.show_choices`; R after a win = replay). End-of-run delays pause with the game and are dropped while leaving (`_leaving`). Splats cost the distance flown at `JUMP_COST_FACTOR` plus `SPLAT_PENALTY_MIN..MAX` scaled by charge. Esc = pause.
- `scripts/maze_tiles.gd` — `MazeTiles.fill`: picks wall/floor tile variants for a maze (game + menu backdrop) and places inner-corner fillets (`Fillets` layer in main.tscn, z 2, above the trail). `scripts/themes.gd` — `Themes`: 10 art themes with alliterative names, one per story level (`BY_LEVEL`; level 1 = Dank Dungeon, the original art), random per randomizer maze (`for_seed`); each has its own tile atlases (`atlas_path`, generated by `tools/make_theme_art.py` into `assets/sprites/themes/<id>_walls/floors/fillets.png`: own palette, three wall constructions (from bricks/blocks/rocks/slabs/cobble/ashlar/soldier/rubble; walls row = construction * 12 + damage * 3 + style, picked in patches by `MazeTiles.construction_at` noise), two wall decorations as styles 1-2, floor base + kind substitutions; the dungeon theme is generated there too) and fog colors (`fog_colors`); the HUD shows the area name as a maze starts. `scripts/fx.gd` — `Fx`: banded additive lights (`make_light`: slime light, chalice glow), goo droplets (`make_drips`) and one-shot `burst`s (landing, splat, chalice).
- `scripts/maze_generator.gd` — `MazeGenerator`: `generate` (story, seeded growing tree) and `generate_noise` (randomizer: noise-guided spanning tree + noise loops, verified by `is_completable`); 1-tile corridors and walls.
- **Hard mode** (`Progress.hard_mode`, checkbox on level select, saved; applies to story + randomizer): cells that have fully dimmed (age >= last `FADE_AFTER`) go back to full fog in `fog.gdshader` and `fog_alpha_at`; returning relights them. HUD shows HARD.
- `scripts/levels.gd` — `Levels`: the 10 level configs (10x6 -> 26x14 cells, paths 22 -> 100 cells, no-upgrade slime targets 45% -> 99% so level 10 needs a perfect run without upgrades) + randomizer config (18-24 x 10-13, 85%) and tile weights. **Tune difficulty here.**
- `scripts/skins.gd` — `Skins`: 10 presets (Lime green starter, one unlocked per level 1-9, ordered so each level's first-run skin suits its theme: Mint for the Mossy Mines ... Frost for the Frozen Fortress, Ember for the Volcanic Vault) + rainbow (after `RAINBOW_RANDOMS` randomizer wins; flowing rainbow wave on the slime, rainbow trail and meter) + custom ("ANY SKIN": color wheel + glow, after level 10); shade derivation (`Skins.shades`: highlight/light/mid/dark/deep/outline) and palette-swap material (`assets/shaders/slime_skin.gdshader` swaps the sheet's six goo shades H/l/m/n/D/G). Check unlocks with `Progress.is_skin_unlocked(id)`. **First-run rule:** a story level never cleared is played in the skin earned by the level before it (`Progress.forced_skin_for`, Lime for level 1; a saved skin that's now locked falls back to Lime on load); the game sets `Progress.skin_override` while it runs, which `skin_color()`/`is_rainbow()`/`glow_amount()` and SkinText respect. Replays and the randomizer use the selected skin. The "first run: playing as ..." notice shows once per level (`Progress.take_skin_notice`, saved).
- **Coins + upgrades** (roguelite layer): story levels hide `Levels.COINS` coins at dead ends (seeded pick, never the start or chalice cell; 165 in all = `Upgrades.full_tree_cost()`), shown as spinning themed coins (`scripts/coin.gd` `Coin`, `assets/sprites/coins.png` from `python tools/make_coins.py`, a row per theme) under the fog; touching one collects it once, saved immediately (`Progress.coins_found`, `collect_coin`, `coin` sound); randomizer mazes have none. HUD: coins in hand beside the slime meter (capped at 999 on screen), coins left to find in this level ("N LEFT" / "ALL FOUND") in a pod under the level name, hidden in randomizer mazes. `scripts/upgrades.gd` `Upgrades`: slime (+10%/level: cost per tile divided), speed (+5%/level), brightness (`light_reach`: the slime's light reveals unexplored floor/walls beyond the trail and relights further), and dev-only wall power; 10 levels each, level n costs n coins; `Progress.buy_upgrade`/`refund_upgrade` (coins can be taken back out), `upgrade_level`, `coins()`. Upgrades screen `scenes/upgrades.tscn` (title: SKINS | UPGRADES row). Wall power (dev mode only, `Progress.dev_tools` from `--unlock-all`, which also gives 999 coins): splats damage the wall hit (health 100, cracks through the art's damage stages) and break it into rubble floor, re-fitting neighbor walls/fillets (`game.gd` `_damage_wall`, `_break_wall`, `crumble` sound); the outer edge can't break. The color wheel no longer has a brightness slider.
- **Hats** (randomizer reward; for now `Hats.available = false`: every hat shows COMING SOON and can't be worn outside dev mode): `scripts/hats.gd` — `Hats.LIST` (id, name, `wins` = randomizer wins to unlock, `column` in `assets/sprites/hats.png`, 16x12 frames from `python tools/make_hats.py`; ten placeholder hats (top hat, beanie, party hat, baseball cap, cowboy hat, chef hat, wizard hat, viking helmet, propeller cap, crown at 1-25 wins) until the user picks the real hats; `--unlock-all` unlocks them all). `scripts/hat.gd` — `Hat` (Sprite2D): sits on the top of the slime's current frame (`Slime.head_point(anim, frame)`, read from the sheet's pixels) so it follows squash and stretch; on `Slime.launched` it pops off with the slime's floor velocity and an arc timed to the leap, so it rides the momentum and drops back on; after a splat it flies on, bounces off walls (`is_wall`), lands and hops back. `Progress.selected_hat` (saved, `select_hat`, `is_hat_unlocked`); `game.gd` `_put_on_hat`; the Skins screen's HATS button flips to a hats page; the title slimes wear it too.
- `scripts/progress.gd` — autoload `Progress`: levels cleared/unlocked, current level, mode (story/random), randomizer wins (`randoms_won`, saved), skin + custom color + glow, key bindings, sound on/off, master volume (`set_volume`/`apply_volume` drive the Master bus); saved to `user://save.cfg`. Debug flags after `--`: `--level=N`, `--unlock-all` (incl. rainbow), `--skin=ID`, `--hard`, `--touch`, `--random` (the last three disable saving), `--hat=ID`, `--quiet-window` (set by play.ps1/screenshot.ps1).
- `scripts/slime.gd` — `Slime` (radius 7; single-axis input centers it in its lane): gliding + charge jump state machine, pinball splat knockback (leftover jump distance becomes a speed; `wall_bounce` reflects the part into the wall at `RESTITUTION` and keeps `WALL_GRIP` of the part along it, so angled splats ricochet (`_ricochet`, `bounced` signal → smaller splat fx in game.gd) until slower than `MIN_BOUNCE_SPEED`; head-on = `BOUNCE_FACTOR` of the leftover; `knocked_back` slides cost no slime), animation selection, `apply_skin`. `scripts/jump_guide.gd` — charge meter + landing dots.
- `scripts/hud.gd` — three framed pods (goo-drop icon + segmented slime meter in the skin color, clock + run timer, level), vignette (`atmosphere.gdshader`), messages on a panel; run timer (`game.run_time`, stops on pause/finish), level text, messages, and the gold NEW RECORD! banner with chalices (`show_record`). Records: `Progress.best_times` per story level (saved under [records]); `record_time` returns true only when an existing record is beaten, so first clears never celebrate. `UIKit.format_time` = m:ss.s; `scripts/chalice.gd` — chalice sparkle.
- `scripts/ui/touch_controls.gd` — `TouchControls` (in main.tscn): floating joystick (left half, snapped to 8 directions), JUMP (right half), pause (top-right); presses the normal input actions; shown on touchscreens or with `--touch`, hidden on keyboard use. `scripts/ui/rotate_hint.gd` — autoload `RotateHint`: rotate-your-phone cover in portrait on touchscreens. Browser fullscreen keeps Esc, so `menu` also has P.
- Ambience (`python tools/make_ambience.py`): every theme loops a bed `assets/sounds/ambient_<theme>.wav` (24 s, seamless) — very faint (`AMBIENT_FAINT_DB`) and tonal/textured rather than plain noise (moaning draft, underground stream, sewer slosh + pipe hum, ghostly choir, singing icy wind, glass hum, crystal shimmer, magma rumble), except the Sunken Shrine's waves and Sandstone Sanctum's sandstorm, which are louder (`AMBIENT_BED_DB`). On top, distant one-off sounds `ambient_<theme>_<n>.wav` (drips, creaks, sludge burps, a faint ghostly scream, icicle drops, glass pings, crystal chimes, magma blorps...) play at random every `AMBIENT_EVENT_GAP` seconds at a random quiet level (`AMBIENT_EVENT_DB`, `AMBIENT_EVENT_TRIM`). All in `game.gd` `_start_ambience`/`_update_ambience`, following the sound on/off setting.
- `scripts/sfx.gd` — autoload `Sfx`: `Sfx.play(name, volume_db, pitch)` / `stop(name)` for the WAVs in `assets/sounds/` (generated by `python tools/make_sounds.py`); silent when `Progress.sound_on` is false.
- Shaders: `assets/shaders/fog.gdshader` (drifting noise mist, soft dithered edges, clear-in on reveal, fade layers, wall shade, glow rings; fog image is plain RGBA8 packing 16-bit last-lit and first-revealed times + a wall bit (`game._fog_color`/`_fog_decode`); float textures don't load on many phones), `slime_skin.gdshader`, `color_wheel.gdshader`.
- `assets/sprites/` — generated by `python tools/make_placeholder_art.py`: `slime_sheet.png` + `slime_sheet.json` (48 animations, built into SpriteFrames by `Slime.load_sprite_frames()`; the slime is a lit dome in six goo shades with a tinted outline, shine, eyes with glints and a soft floor shadow on grounded frames), `chalice_sheet.png` (4 frames of 16x20: polished gold lit from the left, warm brown outline, ruby band, a glint sliding along the rim; the HUD banner uses `CHALICE_FRAME`), `shadow.png`, `walls.png` (16 neighbor masks x 4 damage x 3 styles; exposed corners rounded, `CORNER_RADIUS`), `fillets.png` (16 masks: curved inner-corner pieces for floor tiles, `FILLET_RADIUS`; loaded with `load()`, not `preload`, so a fresh checkout imports cleanly), `floors.png` (8 types x 4 variants).
- itch.io images: `.\tools\promo\make_promo.ps1` renders the cover (`tools/promo/cover.tscn`, own 315x250 SubViewport → 630x500) and 5 screenshots (1280x720) to Desktop\SlimeTime-itch-images. Exports: `export_presets.cfg` (Windows Desktop, Web without threads) → `build/`.
- Generators: `tools/make_coins.py` (spinning themed coins), `tools/make_hats.py` (hat sprites), `tools/make_theme_art.py` (themed tile atlases for levels 2-10; imports helpers from the art script), `tools/make_ui_art.py` (buttons, panels, HUD pod, icons, checkbox, slider knob → `assets/ui/`), `tools/make_placeholder_art.py` (also writes `icon.png`) (sprites/tiles), `tools/make_title.py` (the gooey `title.png` logo, drawn in goo shades so the skin shader tints it), `tools/make_font.py` (pixel font; imports the PNG writer from the art script), `tools/make_sounds.py` (wet/bubbly sound effects built from bubble pops, gloopy pitch bends and muffled noise, pitched low and dark; normalized, so set loudness with `Sfx.play` volume_db), `tools/make_ambience.py` (theme ambience loops; imports helpers from make_sounds). Rerun one after editing it, then re-import.
- `tests/` — `test_phase1-6.gd` + `test_rainbow.gd` (rainbow unlock, randomizer shuffle; runs a game as `current_scene` to exercise the real end-of-maze flow) + `test_skin_rules.gd` (first-run skin rule) + `test_hard_mode.gd` (hard mode fog, one-time notice) + `test_touch.gd` (simulated finger input) + `test_records.gd` (timer, records, NEW RECORD banner) + `test_next_steps.gd` (replay/next buttons; reloads the scene) + `test_bounce.gd` (splat knockback) + `test_themes.gd` (level themes, fillets) + `test_hats.gd` (hat unlocks, riding, popping off and landing back) + `test_coins.gd` (coin budget, collecting, upgrades, dev wall breaking); + `test_pause_restart.gd` (pausing or quitting during the automatic restart after a dry-up); `demo_record.tscn` shows the banner (headless checks; phase 3 plays all 10 levels with the autopilot; phase 5 covers skins, controls, lockstep fade, randomizer completability, menus — it uses a throwaway save), `autopilot.gd` (drives the slime along the shortest path), `demo.tscn` (game + autopilot), `demo_jump.tscn` (splat + charging) `demo_pause.tscn` (pause menu open) and `demo_wipe.tscn` (transition frozen mid-wipe), `demo_dry.tscn` (the dry-up buttons) for screenshots, `demo_record_run.tscn` (watchable: the autopilot beats an easy fake record on level 3) `demo_hats.tscn` (hats page, for screenshots), `demo_hat_hops.tscn` (watchable: the slime leaps up and down a corridor in a hat) and `demo_unlock_all.tscn` (watchable: a fresh throwaway save played through the real menus by the autopilot until every skin is unlocked; never touches the real save).

## Commands (PowerShell, from project root)
Godot isn't on PATH; `tools/godot.ps1` finds the winget-installed console binary.
- Re-import assets after adding/changing files: `.\tools\godot.ps1 --path . --headless --import`
- Smoke-run a scene for errors: `.\tools\godot.ps1 --path . --headless --quit-after 20 res://scenes/title.tscn`
- Tests (run each): `.\tools\godot.ps1 --path . --headless --fixed-fps 60 --quit-after 300000 -s res://tests/test_phase5.gd` (prints `RESULT: PASS`; `--quit-after` stops a test that errors out instead of hanging)
- Screenshot: `.\tools\screenshot.ps1 [-Frames 30] [-Scene res://tests/demo.tscn] [-Level N] [-GameArgs --unlock-all,--skin=custom,--random]` → `.screens/latest.png` (view it with Read). Each run clears `.screens/`.
- Inspect a screenshot up close: `python tools/upscale_png.py .screens/latest.png .screens/zoom.png 4 [x y w h]`

## Workflow
- Launching for the user to play: always use `.\tools\play.ps1` (run in the background) - it opens the window centered on their right-most monitor from the first frame and without taking focus, so their borderless-fullscreen game on the other screen stays in front until they click over. "Launch" = their real save: `.\tools\play.ps1`; "dev mode" = everything unlocked, nothing saved: `.\tools\play.ps1 -Dev`; a demo: `.\tools\play.ps1 -Dev -Scene res://tests/demo_record_run.tscn`. Don't launch with godot.ps1 directly (that window grabs focus on the main monitor). `tools/screenshot.ps1` uses the same quiet window (`tools/quiet_window.ps1`: `--position` + a temporary `override.cfg` with `no_focus`, which the game deletes on start via `--quiet-window`).
- After gameplay or visual changes: run the tests and take a screenshot to confirm before reporting done.
- Input actions in `project.godot` `[input]`: `move_left/right/up/down` (WASD + arrows), `jump` (Space), `restart` (R), `menu` (Esc = pause / back, not remappable). `Progress.apply_bindings()` replaces the remappable ones at startup.
- In canvas_item shaders, fragment `COLOR` already includes the texture; pass modulate through a varying if you need it (see `slime_skin.gdshader`).
- The Godot editor may be open and rewrites `project.godot` in its own format; keep edits compatible.
- Write files as UTF-8 without BOM (PowerShell's `Set-Content -Encoding utf8` adds one).
- Commit working states with git so changes can be rolled back.
