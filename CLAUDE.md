# Slime Time

2D pixel-art game in **Godot 4.7** (GDScript). A slime glides through a pitch-black maze; its goo trail reveals the map, moving drains the slime meter, and a golden chalice is the exit. Full design and build phases: [docs/game-design.md](docs/game-design.md). **All 6 build phases are done.** Further work is tuning, content and polish requested by the user.

## Pixel-art rules (keep these consistent)
- Base resolution **320x180**, window 1280x720, stretch mode `viewport` + `integer` scaling.
- **16x16 tiles**; slime frames are 20x20 (≈14 px body, room to squash/stretch). Nearest-neighbor filtering is the project default; never enable texture filtering. UI text uses the generated pixel font (`assets/fonts/pixel.fnt`, 5x7 glyphs, project default font): size 8 for text, 16 for titles (integer-scaled).
- `snap_2d_transforms_to_pixel` is on; avoid sub-pixel scaling or rotation of sprites.
- Colors come from the palette in `tools/make_placeholder_art.py` (`PAL`). New art should reuse it.

## Layout
- Scenes: `title.tscn` (main scene: start page) → `level_select.tscn`, `skins.tscn`, `controls.tscn` (remapping + sound toggle), `main.tscn` (gameplay, includes the pause menu), `victory.tscn` (after level 10). Menu scripts in `scripts/ui/` (`ui_kit.gd` = shared theme/helpers + button click sound, `color_wheel.gd`, `pause_menu.gd`).
- `scripts/game.gd` — gameplay: story level or randomizer maze (`random_seed`), tile variant choice, fog/trail reveal on a 2 px grid with stepped fade-back (`FADE_AFTER`/`FADE_ALPHA`; walls dim in lockstep, `WALL_FOG_ALPHA` darker), skin colors, glow, splat screen shake, win/lose flow. Splats cost the distance flown at `JUMP_COST_FACTOR` plus `SPLAT_PENALTY_MIN..MAX` scaled by charge. Esc = pause.
- `scripts/maze_generator.gd` — `MazeGenerator`: `generate` (story, seeded growing tree) and `generate_noise` (randomizer: noise-guided spanning tree + noise loops, verified by `is_completable`); 1-tile corridors and walls.
- `scripts/levels.gd` — `Levels`: the 10 level configs + randomizer config and tile weights. **Tune difficulty here.**
- `scripts/skins.gd` — `Skins`: 10 presets (Ember orange default, one unlocked per level 1-9) + custom (after level 10); shade derivation and palette-swap material (`assets/shaders/slime_skin.gdshader`).
- `scripts/progress.gd` — autoload `Progress`: levels cleared/unlocked, current level, mode (story/random), skin + custom color + glow, key bindings, sound on/off; saved to `user://save.cfg`. Debug flags after `--`: `--level=N`, `--unlock-all`, `--skin=ID`, `--random` (the last three disable saving).
- `scripts/slime.gd` — `Slime` (radius 7; single-axis input centers it in its lane): gliding + charge jump state machine, animation selection, `apply_skin`. `scripts/jump_guide.gd` — charge meter + landing dots.
- `scripts/hud.gd` — slime meter (skin color) + level text + messages; `scripts/chalice.gd` — chalice sparkle.
- `scripts/sfx.gd` — autoload `Sfx`: `Sfx.play(name, volume_db, pitch)` / `stop(name)` for the WAVs in `assets/sounds/` (generated by `python tools/make_sounds.py`); silent when `Progress.sound_on` is false.
- Shaders: `assets/shaders/fog.gdshader` (drifting noise mist, soft dithered edges, clear-in on reveal, fade layers, wall shade, glow rings; fog image is RGBF: last lit / kind / first revealed), `slime_skin.gdshader`, `color_wheel.gdshader`.
- `assets/sprites/` — generated by `python tools/make_placeholder_art.py`: `slime_sheet.png` + `slime_sheet.json` (48 animations, built into SpriteFrames by `Slime.load_sprite_frames()`), `chalice_sheet.png`, `shadow.png`, `walls.png` (16 neighbor masks x 4 damage x 3 styles), `floors.png` (8 types x 4 variants).
- Generators: `tools/make_placeholder_art.py` (sprites/tiles), `tools/make_font.py` (pixel font; imports the PNG writer from the art script), `tools/make_sounds.py` (sound effects). Rerun one after editing it, then re-import.
- `tests/` — `test_phase1-6.gd` (headless checks; phase 3 plays all 10 levels with the autopilot; phase 5 covers skins, controls, lockstep fade, randomizer completability, menus — it uses a throwaway save), `autopilot.gd` (drives the slime along the shortest path), `demo.tscn` (game + autopilot), `demo_jump.tscn` (splat + charging) and `demo_pause.tscn` (pause menu open) for screenshots.

## Commands (PowerShell, from project root)
Godot isn't on PATH; `tools/godot.ps1` finds the winget-installed console binary.
- Re-import assets after adding/changing files: `.\tools\godot.ps1 --path . --headless --import`
- Smoke-run a scene for errors: `.\tools\godot.ps1 --path . --headless --quit-after 20 res://scenes/title.tscn`
- Tests (run each): `.\tools\godot.ps1 --path . --headless --fixed-fps 60 --quit-after 300000 -s res://tests/test_phase5.gd` (prints `RESULT: PASS`; `--quit-after` stops a test that errors out instead of hanging)
- Screenshot: `.\tools\screenshot.ps1 [-Frames 30] [-Scene res://tests/demo.tscn] [-Level N] [-GameArgs --unlock-all,--skin=custom,--random]` → `.screens/latest.png` (view it with Read). Each run clears `.screens/`.
- Inspect a screenshot up close: `python tools/upscale_png.py .screens/latest.png .screens/zoom.png 4 [x y w h]`

## Workflow
- After gameplay or visual changes: run the tests and take a screenshot to confirm before reporting done.
- Input actions in `project.godot` `[input]`: `move_left/right/up/down` (WASD + arrows), `jump` (Space), `restart` (R), `menu` (Esc = pause / back, not remappable). `Progress.apply_bindings()` replaces the remappable ones at startup.
- In canvas_item shaders, fragment `COLOR` already includes the texture; pass modulate through a varying if you need it (see `slime_skin.gdshader`).
- The Godot editor may be open and rewrites `project.godot` in its own format; keep edits compatible.
- Write files as UTF-8 without BOM (PowerShell's `Set-Content -Encoding utf8` adds one).
- Commit working states with git so changes can be rolled back.
