# Glossary: Traditional Chinese (zh_TW, Taiwan)

Written for Taiwan players, not converted from zh_CN: Taiwan vocabulary throughout (設定, 儲存, 造型, 手把,
全螢幕, 裝置, 貼上, 劇情, 過關, 軌跡, 碼錶, 萊姆, 紳士帽, 毛帽, 衣櫃, 加成, 音效, 離開). Register: plain, informal,
no 您. No spaces between words; full-width `，。！？：（）、`; `{placeholders}`, digits and Latin units half-width;
layout gaps from the English kept. Widths measured with Fusion Pixel 10 px zh_tw (Hanzi and full-width
punctuation 10 px) plus the slimy font for digits / Latin, placeholders filled with 888: every entry is
inside its `max Npx` budget.

## Doubts for a native reviewer

1. **SLIMAKAZE = 史萊瑪卡茲** (sound only, pun lost). 神風 would carry the pun; it is less loaded in Taiwan than on the
   mainland, so 史萊神風 is a possible Taiwan-only choice if the reviewer prefers.
2. **CHAMELEON = 卡魅龍** (sound transliteration per the style guide); 變色龍 may read better.
3. **INKKY = 印奇**.
4. **Tagline** 逃離迷霧 / 不乾不休: pun on 不死不休 ("never stop till dead") with 乾 "dry".
5. **DRIED UP = 乾掉了**: colloquial and funny, but 乾掉 also means "down a drink"; switch to 乾涸了 if it reads wrong.
6. **GROUNDED = 禁足** (grounded as a punishment), **FOG BITES = 迷霧反撲**, **SECOND WIND = 續命** (slangy).
7. **CHALICE CONSUMED! = 聖杯吞下肚！**; **JIGGLES = Q彈** in story line 7.
8. Ford joke `(ANY COLOR YOU LIKE)` = （顏色任你挑）: the quote is not well known, kept as a plain promise.
9. **skin = 造型** (Taiwan usage) everywhere, including `NEW JELLY SKIN` 新果凍造型.
10. **PAID RUN = 有獎局**, **DESCENT = 深入**: functional choices, Descent is switched off today.
11. `language.title` (LANGUAGE screen, new in code, not yet in messages.pot) is already translated: 語言.
